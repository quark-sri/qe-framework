# Glossary

| Term | Meaning |
| --- | --- |
| Order | A confirmed purchase by one customer. See `entity.order`. |
| Paid order | An order with a captured payment. |
| Refund | Money returned to the customer for all or part of a paid order. See `entity.refund`. |
| Refund window | The number of days after delivery in which a customer can request a refund. See `REF-001`. |
| Partial refund | A refund for less than the refundable amount. |
| Refundable amount | Order total minus refunds already made. |
| Support agent | Staff user who can approve refunds within a limit. |
